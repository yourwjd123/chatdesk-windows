# ChatDesk 0.1 Windows 验证版

独立的中文桌面对话工具。支持 DeepSeek 以及 OpenAI 兼容 HTTPS 聊天接口。
本包是可运行源码和 Windows 打包脚本，不包含已编译的 EXE。

## Windows 启动

1. 将整个文件夹解压到自己选择的**非系统盘本地目录**，例如 `D:\Apps\ChatDesk`。
2. 电脑需已有 Python 3.11 或更新版本，包含 Tcl/Tk 和 pip（推荐 python.org 官方 Python）。在终端运行 `python --version` 可检查。无需安装 ComfyUI。
3. 双击 `start.bat`。首次会从 PyPI 下载 cryptography，并在程序文件夹内创建 `.venv` 和 `runtime`。安装过程需要网络。
4. 每次启动选择数据目录，例如 `D:\ChatDeskData`。软件不在 AppData 等位置保存目录选择，所以每次需重新选择同一个目录来恢复记录。
5. 首次设置至少 12 位主密码，再次启动输入该密码。**忘记密码无法找回已保存密钥**。请做好独立备份。
6. 点击“API 配置 / 密钥”，填写服务名称、模型和接口地址，保存自己的密钥。
7. 新建或选择会话，设置背景提示词和生成参数，输入消息并发送。

DeepSeek 示例：

- 名称：`DeepSeek`
- 基础地址：`https://api.deepseek.com/v1`
- 模型：`deepseek-chat`

其他 OpenAI 兼容服务：填写其 `/v1` 基础地址；也可填写完整 `/chat/completions` 地址。
不兼容 OpenAI 聊天格式的专有接口暂不支持。不使用环境代理、不跟随 HTTP 重定向，以避免认证头被转发。仅接受 HTTPS 地址。
API 调用会把选定的背景提示词、保留的会话历史及本次输入发送给选定服务；认证密钥仅发送给该服务。

## 对话和生成参数

- 每个会话独立保存背景提示词、参数、服务选择及消息。
- 温度控制随机性；严格、平衡、自由是提示词预设，不保证模型严格服从。
- “期望字符”是发给模型的长度要求，0 表示不附加要求，不硬截断。
- “最大 token”是 API 的生成上限，**不等于字符数**。模型实际支持范围以服务文档为准。
- “保留最近轮数”控制向服务发送的近期历史。早期消息仍留在本地，可导出，但不会发送。尚无自动摘要、token 预算预估；遇到上下文超限可调低保留轮数。
- 流式显示回答；停止生成需要等待当前网络读取返回，最长约 30 秒。停止或失败的回答标为未完成，不加入后续请求。
- 生成期间禁止切换、删除会话或修改本次请求参数；需先停止或等待结束。
- 背景提示词与参数可通过“保存设置”保存，发送、切换会话和关闭时也保存。
- 当前会话可重命名或删除。第一版不提供消息编辑、重生成、搜索、富文本渲染。

## 手动另存为

点击“另存最近回答”或“另存完整对话”，选择 `.txt` 或 `.md` 和自己的文件名、目录。
完整对话导出前可决定是否包含背景提示词。UTF-8 编码，MD 保留模型返回的代码块等文本。
未完成的回答在完整导出中有标记。这里的最近回答指最近一条助手回答；尚未提供任意单条历史消息选择。
导出完全由用户触发，不自动导出。覆盖现有文件需在 Windows 保存对话框中确认。

## 存储与保密

所有由软件管理的文件仅写入用户指定的本地非系统盘位置：

- 程序目录：源码/EXE、依赖、构建输出、安装及构建临时文件。
- 每次选择的数据目录：`vault.enc`（加密密钥库）、`conversations.json`（配置、提示词和历史）、`runtime`（运行临时目录）。
- 导出文件：每次另存时自行选择。

系统盘按 Windows `SystemDrive` 判断，不简单假定为 C 盘。拒绝 UNC 网络目录；使用 Python 解析目录链接后再次检查系统盘。指定位置不可写时提示错误，不回退至系统盘。
软件本身不生成任务日志、原始 HTTP 日志、异常堆栈文件、内存转储或自动遥测，不上传诊断信息。
主密码通过 scrypt 派生 AES-256-GCM 密钥；盐和随机 nonce 存入密钥库，主密码不落盘。
普通配置不保存密钥；已知密钥在历史保存、展示和导出时再次脱敏。不得在聊天中手动粘贴其他未录入密钥库的秘密；程序无法识别所有未知秘密。
**会话正文和背景提示词默认以明文本地保存**；密钥库才使用加密。导出的 TXT/MD 也是明文。
加密密钥必须在运行内存中使用。Windows/安全软件自行创建的分页文件、系统级崩溃转储、杀毒隔离或其他系统记录不受本软件控制，不能承诺这些系统行为绝不涉及系统盘或进程内存。

保存密钥前先确认 API 地址可信。仅使用自己的密钥，不要将真实密钥发到 GitHub 或问题反馈中。

## 生成便携 EXE

在 Windows 非系统盘内双击 `build.bat`，会在程序目录中安装固定版本的 PyInstaller 并生成：

`dist\ChatDesk\ChatDesk.exe`

必须保留或复制**整个 `ChatDesk` 文件夹**，不可只复制 EXE。
使用 onedir 模式，避免 onefile 自解压到系统 TEMP。所有构建缓存与临时文件重定向到程序目录。
生成后可在没有 Python 的 Windows 电脑上测试运行；应用未做代码签名。
