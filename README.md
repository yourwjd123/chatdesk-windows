## 本版交互

- 写作 / AI讨论双模式：写作时正文与AI并排；讨论时对话占主工作区，返回后保留文档、选区、撤销历史和滚动位置。导航可收起，正文可专注阅读。
- AI消息独立滚动，输入区固定在底部。模型、附件、历史操作收进就近菜单，不再重复显示消息选择列表，也不滚动整个助手栏。
- 章节与讨论独立：打开、新建章节不自动新建或切换讨论；切换讨论也不跳转正文。自由讨论通过“引用”选择器明确选择章节，或只引用作品资料。
- 普通发送直接执行，不连续弹确认窗口。顶部“本次引用”显示资料数量与粗略token估计，可主动查看、勾选和调整预算。
- Ctrl+S保存当前草稿。AI修改应用前自动保存原版本；历史入口也可手动建立快照。草稿约1.5秒加密自动保存。

## 从构思阶段就有AI

新作品首先打开“创意与设定”，无需先填完整表单：

- 创意构思：提出不同故事方向或先讨论、澄清想法。
- 故事大纲：从空白起草、或共同完善已有大纲。
- 背景设定 / 人物：直接AI起草候选，也可自己新增和编辑。
- 文风与要求：AI起草风格方案，再由作者修改确认。
- 章节规划：AI生成分卷/章节条目，在表格中查看、编辑、勾选后才建立章节。可以把首条计划写入现有空白占位章，保留其ID和已有关联。

点击AI操作只准备任务，不立即消耗API额度；输入框可填写补充要求，也可留空后点击发送。讨论与候选不会自动变成正式设定。

## 正文共同修改

选中文本后显示润色、扩写、压缩操作，也可通过右键调用。续写、摘要和审稿按当前文档确定目标。

结果随消息保存任务目标：选段结果直接比较原选段与候选；续写插入原位置；大纲、背景、人物、摘要有各自明确的采用按钮。用户可先修改候选，确认后才写入。

如果原文或章节结构在生成期间发生变化，旧候选不能直接覆盖新内容；仍可查看、复制或重新生成。选区按Unicode正确处理，包括表情符号。

生成期间可查看和编辑其他文档、切换讨论或作品。结果仍只进入发起时的原讨论；“查看生成 / 查看结果”可主动返回，不抢走当前编辑位置。同一时间只运行一个AI请求。

审稿不会直接覆盖正文，可按已确认意见准备新的修稿候选。生成中断保留不完整内容，可复制或再试一版。

## 长篇上下文

保留总纲、章节计划、人工确认摘要、近期正文、相关设定和早期正文片段检索。默认作品资料预算32000字符，可在引用检查中调整。完整章节只在明确需要时选取；超预算会提示，不静默截断总纲。

自由讨论的引用选择与编辑位置独立；写作任务临时引用它所绑定的章节，任务提示和引用摘要可见。被排除、已删除和未完成消息不进入后续会话上下文。

本地关键词检索不是语义向量检索，不保证模型永不遗忘或矛盾。实际上下文容量和token参数支持以模型服务为准，粗略token估计不作为计费依据。

## 用户、外观、附件与安全

原有用户隔离、本地主密码、scrypt + AES-256-GCM、加密会话/作品/附件、备份恢复、字体和背景图保留。新增正文、AI阅读区、界面字号分别配置。

数据根目录仍在启动时自行选择，程序、依赖、临时文件、导出和备份均使用用户选择的非系统盘目录；不可写时不回退系统盘。密钥不进明文配置、导出、请求日志或异常记录。系统分页、系统转储和第三方程序不由应用控制；运行内存无法保证物理清零。

支持20 MiB以内TXT/MD/CSV、文字PDF、DOCX与PNG/JPEG/WebP，图片需模型支持视觉。附件原件加密保存，用户主动选择是否发送。TXT/MD手动导出为明文，已配置密钥会脱敏，未知秘密需自行检查。

## 源码运行与发布

源码运行需Python 3.11–3.13。把整个文件夹放在非系统盘，双击 `start.bat`；首次联网安装固定依赖，虚拟环境和安装临时文件在程序目录。Windows `build.bat` 生成整个 `dist/ChatDesk/` 便携文件夹。

源码自检：`python -B app.py --self-test`。自动测试：`python -B -m unittest discover -v`。

发布流程已改为显式手动选择：普通push不发布；只有经用户确认后手动运行工作流并勾选 `publish_release` 才能在测试和EXE自检通过后上传Release。构建二进制不提交到Git；新版验证并发布成功后再清理旧版安装包，保留必要源码历史。
