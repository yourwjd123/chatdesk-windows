# ChatDesk 0.2 · Windows 多用户对话工具

独立中文桌面应用，使用 PySide6。支持 DeepSeek / OpenAI 兼容 HTTPS API、多轮聊天、独立背景提示词、附件、加密本地账户和手动 TXT/Markdown 导出。

## 启动与便携版

1. 将整个源码文件夹解压到自己选择的**非系统盘本地目录**，例如 `D:\Apps\ChatDesk`。
2. 已安装 Python 3.11–3.13 的电脑可双击 `start.bat`。首次从 PyPI 安装固定版本依赖；虚拟环境 `.venv` 与安装缓存/临时文件均放在程序目录，安装失败不会回退系统目录。
3. 启动后选择数据根目录，例如 `D:\ChatDeskData`。首次“新建用户”，设置至少12位的本地密码；之后用同一个根目录登录。
4. 在“设置 → API与模型”填写自己的API密钥、地址和模型，点击“应用并关闭”。
5. 每次启动重新选择数据根目录，程序不在 AppData 或注册表保存该选择。

DeepSeek 默认地址 `https://api.deepseek.com/v1`，默认模型 `deepseek-chat`。
其他服务须兼容 OpenAI `/chat/completions`；也接受完整 HTTPS 聊天接口地址。不使用环境代理，不自动跟随重定向。

双击 `build.bat` 可在 Windows 构建 `dist\ChatDesk\ChatDesk.exe`。分发时复制**整个 ChatDesk 文件夹**，不是单独的EXE。构建使用 onedir，不采用解压到系统 TEMP 的 onefile。

仓库附有 Windows Actions 自动验证/打包流程。若运行成功，可在 [Actions](https://github.com/yourwjd123/chatdesk-windows/actions) 对应运行的 Artifacts 中下载 `ChatDesk-0.2-Windows-portable`；下载可能需要登录GitHub。没有有效构建记录时请使用源码和 `build.bat`，不要将尚未完成的构建视为可用安装包。

## 用户与数据隔离

- 登录页支持新建、登录、删除用户，以及恢复加密备份。
- “设置 → 用户与安全”可改名、改密码、设置1–120分钟空闲自动锁定。改名和改密通过各自按钮立即生效并单独确认；取消设置不会撤销，其他偏好用底部“应用并关闭”保存。
- “锁定 / 切换用户”关闭当前会话视图、清理凭据控件和用户对象，回到登录页。生成中会先隐藏界面并停止请求，读取超时最长约30秒后返回登录。
- 用户目录使用随机ID，改名不移动目录。不同用户使用独立随机加密密钥。
- 删除用户需要密码及明确确认，将删除该用户所有会话、配置和附件；建议先备份。普通删除不保证SSD或备份介质上物理不可恢复。
- 同一数据根目录只允许一个应用实例，避免并发覆盖。运行异常退出后，如锁文件未释放，请确认无旧进程后再处理 `application.lock`；不要在程序运行时手动删除。

### 存储结构

```text
自行选择的数据根目录/
  users.json                  # 用户名与随机ID索引（明文，不含密码/密钥）
  application.lock            # 运行实例锁，不含凭据
  users/<随机用户ID>/
    account.json              # salt 与加密封装的数据密钥
    state.enc                 # 加密的配置、API密钥、会话、解析文本和外观设置
    attachments/<随机ID>.enc  # 加密的附件原件，包括背景图片
```

密码通过 scrypt 派生密钥，AES-256-GCM 加密数据。修改密码只重新封装随机数据密钥，不生成明文中间文件。附件内容仅在解析、预览、发送或备份时于内存解密。**忘记用户密码无法恢复数据**，不存在管理员后门。

用户隔离与静态加密不能抵御已控制操作系统的恶意程序。Python/Qt无法保证内存物理清零；Windows分页、系统转储、防病毒软件等系统级记录不受应用控制。应用自身不记录请求对象、原始认证头、响应错误正文或异常堆栈，不创建内存转储，不上传诊断信息。

所有应用管理的资产只写入选择的非系统盘本地目录；解析目录链接后检查，拒绝系统盘和UNC网络目录。程序、依赖、构建临时文件放在所选程序目录；用户数据放在所选数据根目录；导出与备份每次另选位置。移动数据时先退出，完整复制根目录，再在下次启动选择新目录。

## 会话与参数

- 每个会话有独立背景提示词、服务选择、温度、最大输出token、期望字符、历史轮数与遵循预设。
- “设置 → 新会话默认值”只影响以后新建的会话；当前会话可直接调整并保存。
- 温度控制随机性；“严格/平衡/自由”只是提示词预设，不能保证模型服从。期望字符为软要求，0表示不限；token不是汉字数。
- 发送前显示消息数和粗略输入token估计。此值不是模型tokenizer的结果，不作为计费值；图片估算误差较大。实际上下文容量由模型决定，超限可减少保留轮数或取消附件。
- 历史超过近期轮数不发送但仍保存；停止或失败的回答不作为后续上下文。暂不自动摘要。
- 切换会话、锁定和正常关闭时保存未发送草稿与附件选择，重新解锁可继续编辑；不保证异常断电时恢复最近输入。
- 流式显示Markdown，可停止生成；正文渲染禁止加载模型输出中的外部图片或本地文件，链接不自动打开。
- `Ctrl+Enter` 发送，顶部按钮快速缩放正文字号。

## 上传附件

支持单文件最多20 MiB：TXT、MD、CSV、可提取文字的PDF、DOCX、PNG、JPEG、WebP。文本尝试UTF-8/GB18030；解析文本最多保留20万字符，截取时有标记。扫描PDF暂不OCR；加密PDF暂不支持；图片最多3000万像素。

点击“上传附件”后，原件立即加密复制到本用户目录。即使尚未发送，文件也保留在账户附件库，源文件移动不会影响使用。可预览、复用或删除附件。

附件列表复选框决定该附件是否参与本会话后续请求：

- 文档：把解析出的文本放入所属用户消息，保留文件名称标记。
- 图片：只有在“设置 → API与模型”明确勾选视觉能力后，才可按 OpenAI 图片输入格式发送；软件不自动判断服务能力。默认DeepSeek配置不勾选视觉能力。接口不支持时请取消该图片参与发送或更换服务。
- 近期历史中的附件可反复发送并产生费用；取消复选后不发送，但仍保留原件。历史消息超出保留窗口时，其附件也不发送。
- 删除附件会移除本用户所有会话中的引用；正在使用的背景图需先从外观设置移除。

附件、背景及聊天内容不是应用指令，不会被应用执行；文档内容发往模型后仍可能影响模型行为，请自行确认来源。

## 外观与统一设置

“设置”下有用户与安全、API与模型、新会话默认值、外观、数据与附件五页。

外观支持正文/输入字体、代码字体、字号、浅色/深色主题；可加密导入背景图片，选择填充/适应/居中及遮罩强度，恢复默认外观或纯色背景。字体提供即时预览。应用前不改变当前会话参数。

API页切换编辑项前先点击“保存本项编辑”；最终“应用并关闭”才写入配置。选择的背景图片会立即加入加密附件库，取消设置后仍可在附件管理中清理。

## 导出、备份与旧版迁移

- 主界面“另存最近回答”“另存完整会话”由用户主动选择TXT或MD及路径；完整导出可选背景提示词。UTF-8，附件仅列名称，不自动导出原件。
- **TXT/MD为明文**；软件会脱敏已配置的API密钥，但无法识别所有未知秘密，请自行检查内容。
- “设置 → 数据与附件”创建独立密码保护的 `.cdbak` 备份，包含该用户全部已保存配置、会话、密钥和附件。无明文ZIP或临时解密文件。先应用设置再备份。
- 登录页恢复备份时输入备份密码，然后设置新的用户名和登录密码，恢复成独立用户，不覆盖已有用户。备份上限256 MiB，当前适合小型本地账户。
- “从0.1版导入”选择旧数据目录和原主密码，会导入旧API配置与会话到当前账户；旧文件保持原样。反复导入可能产生重复会话。原0.1版会话文件为明文，确认迁移成功后请自行决定如何保管或删除原件。

## 验证与仓库

见 `VALIDATION.md`，自动检查：`python -B -m unittest discover -v`。离屏Qt测试不调用真实API，不使用真实密钥。

公开仓库仅包含源码、文档、测试和构建流程。不要提交数据根目录、密码、密钥、会话、备份和手动导出的文档。`.gitignore`是辅助措施，不能替代上传前检查。
