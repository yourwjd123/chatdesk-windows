# 墨舟 Novel Studio 0.3 · 小说创作工作台

基于 PySide6 的 Windows 本地小说工作台，支持 DeepSeek / OpenAI兼容API。三栏布局：作品导航、正文编辑、AI创作助手。

[下载 Windows x64 便携版](https://github.com/yourwjd123/chatdesk-windows/releases/download/v0.3.2/Mozhou-0.3.2-Windows-x64.zip) · [发布记录](https://github.com/yourwjd123/chatdesk-windows/releases/tag/v0.3.2) · [自动验证](https://github.com/yourwjd123/chatdesk-windows/actions)

首次发布或更新构建期间，下载链接需等待对应Windows流程成功。当前源码不会把构建文件提交进Git历史；大文件仅作为最新Release资产保存。

## 启动与升级

完整解压到自己选择的**非系统盘本地文件夹**，保留 `_internal` 等依赖，双击 `ChatDesk.exe`，无需Python。目标Windows 10/11 x64，自动验证使用Windows Server x64。

启动时选择数据根目录，新建或登录本地用户。在“设置 → API与模型”填写自备密钥。默认DeepSeek地址 `https://api.deepseek.com/v1`、模型 `deepseek-chat`。其他API须兼容 OpenAI `/chat/completions`，仅HTTPS，不自动跟随重定向、不使用环境代理。

升级前可在旧版设置中创建加密备份。0.3可以直接打开0.2的数据根目录；旧会话保留在“未归档对话”，新作品单独管理。恢复0.2备份也可使用。0.1数据通过“设置 → 数据与附件 → 从0.1版导入”导入，原文件不会删除。

## 长篇小说的资料与上下文

作品导航支持作品简介、总纲、风格约束、分卷章节、章节计划、正文、人工确认摘要，以及人物、世界观、关系地点、时间线、剧情状态、伏笔资料。章节可上下移动；资料可以固定参与上下文。

AI不会自动记住整部小说。每次请求由以下资料组成：

1. 作品总纲与风格、当前章节计划：默认必选，不静默截断。
2. 当前章节已确认摘要、正文末尾最多6000字符、上一章末尾最多3000字符。
3. 最近已完成章节的人工摘要、关键词匹配的早期摘要与设定；固定资料优先选取。还会从更早的正式正文中检索最多8段相关片段，即使未填写摘要也可找回细节；章节全文可手动勾选，未来章节默认不参与。
4. 当前对话中保留且未排除的消息、参与发送的附件。

作品资料在“检查上下文”和发送前都能逐项预览、勾选，显示未参与的资料。默认作品资料预算32000字符，可调整；预算不含对话历史和附件，不等于模型token上限。总纲或手动选取资料超出预算时明确提示，不能静默截断。自动选取采用本地关键词匹配，不使用外部嵌入服务。

“总结本章”“检查矛盾”默认请求携带完整当前章节，超过预算时需自行精简或增加预算。全文不自动拆分；模型实际上下文容量由服务决定，发送前会显示完整请求粗略token估计，必要时减少资料或保留轮数。

## 正文与AI候选严格分开

中央是作者正文，右侧是讨论与候选。快捷操作支持续写、润色/扩写/压缩选段、总结本章、检查矛盾。

AI回答不会自动改变正文、摘要、人物状态或伏笔。选中右侧记录并点击“采纳候选”，可先编辑候选，再决定插入正文、替换选段/整章、保存为摘要或新增正式资料。新的剧情状态与摘要需要作者检查确认，模型检查结果也是建议，不保证无误。

总纲和资料可以随时人工编辑；已有正式资料不会因为删除某条AI回复而自动回滚。需要改正已采纳内容时，编辑文档或恢复历史版本。

## 回复控制、分支与版本

右侧记录选择器支持：

- 排除/恢复：记录仍可见，但被排除消息不再发送给模型。
- 删除回复：从当前讨论移除，不再发送；可撤销最近20次删除。撤销缓存仍加密保留，删除并非物理擦除。
- 从此处分支：保留截至选中消息的内容，在独立讨论中继续，原分支不变。
- 另一候选：回到所选助手回复之前的问题，将问题作为新分支草稿；点击发送生成其他候选，原答案不会带入。

删除早期回复不能消除它已经对后续答案造成的影响，纠错时应从出错前创建分支。AI候选本身不进入正式资料检索。

正文和资料编辑后约1.5秒加密自动保存草稿；Ctrl+S或“保存版本”建立手动版本，最近50个历史版本可查看差异和恢复。恢复前保留当前内容。自动保存不会为每次按键建立版本。关闭、锁定、切换会保存草稿，但异常断电仍可能丢失最近输入。

## UI与快捷操作

左侧书架和章节资料，中央正文/章节计划/确认摘要，右侧创作助手；小屏幕下助手区可滚动。“专注写作”隐藏两侧，再次点击恢复。Ctrl+S保存版本，Ctrl+Enter发送AI请求。

设置集中在顶部“设置”：用户与安全、API与模型、新会话默认值、外观、数据与附件。支持正文和代码字体、字号、浅/深色、加密背景图片与遮罩。讨论专属的背景提示词和生成参数通过右侧按钮调整。

期望字符为软要求；最大token是服务生成量限制，不是汉字数；“严格/平衡/自由”为提示词预设。流式生成可停止，网络读取超时最长约30秒；不完整回答不进入后续上下文。

## 用户、附件与导出

每个本地用户有独立配置、密钥、作品、历史、附件和外观；支持新建、改名、改密、切换、删除、自动锁定。密码至少12位，忘记后无法恢复。用户名和密码修改通过专门按钮立即生效；删除用户须确认并验证密码。

支持最多20 MiB的TXT/MD/CSV、文字PDF、DOCX、PNG/JPEG/WebP。附件原件加密保存，文本解析最多20万字符，截取有标记。扫描PDF不OCR；图片最多3000万像素，仅在自行确认模型支持视觉并勾选能力后发送。可预览、复用、取消发送或删除；删除会清理会话引用及删除撤销缓存中的引用。

“导出正文”手动另存当前作品全部章节；“导出回答/讨论”手动导出TXT/MD，可选择是否包含背景提示词。导出是UTF-8明文；已配置API密钥会脱敏，但无法识别所有未知秘密。附件只列名称，不自动导出原件。

“设置 → 数据与附件”支持独立密码的`.cdbak`加密备份，包含当前用户作品、配置、会话、版本和附件。登录页可恢复为新用户，不覆盖原账户；备份文件最大256 MiB，大附件处理可能短暂阻塞界面。

## 本地安全与存放目录

程序、运行/构建临时文件位于所选非系统盘程序目录；配置、作品、附件等位于所选非系统盘数据根目录；导出与备份每次自行选址。解析目录链接后拒绝系统盘及UNC路径，写入失败不回退系统盘。不使用QSettings、自动遥测或异常上传，不保存原始HTTP错误、请求认证头、堆栈或内存转储。

```text
数据根目录/
  users.json                   # 用户名/随机ID索引，明文，不含密码
  application.lock             # 单实例锁
  users/<随机ID>/
    account.json               # salt与加密封装的数据密钥
    state.enc                  # 加密作品/版本/配置/密钥/会话/附件解析文本
    attachments/<随机ID>.enc   # 加密附件及背景图原件
```

使用scrypt与AES-256-GCM。密码不落盘，修改密码重新封装独立随机密钥。运行时必须在内存中使用解密内容，不能保证物理内存清零；Windows分页、系统转储和第三方安全软件的系统级记录不由应用控制。普通删除不保证磁盘物理擦除。

## 源码与构建

源码运行需已有Python 3.11–3.13，双击`start.bat`。首次联网安装固定版本依赖，虚拟环境与缓存都在程序目录。Windows双击`build.bat`生成`dist/ChatDesk/ChatDesk.exe`；复制整个文件夹。

Windows发布流程只有在自动测试和打包EXE自检通过后上传Release ZIP。旧版发布包和Actions构建附件会在新版成功后清理，避免重复占用空间。必要源码历史保留，不在Git仓库存放二进制、用户数据、密钥或个人导出。

测试见`VALIDATION.md`；运行：`python -B -m unittest discover -v`。
